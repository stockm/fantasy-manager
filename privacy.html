Privacy statement

Fantasy Manager is being developed as an AI-assisted fantasy football management tool by Kreativ Software LLC.

AUTHORIZATION

User-controlled access

The application is intended to access a user's fantasy information only after the user explicitly authorizes access through the applicable OAuth flow. Access is intended solely to provide fantasy-management features requested by that user.

01

Credentials

Client secrets, OAuth tokens, passwords, and other authentication credentials are not intended to be published in this repository.

02

Data use

Authorized fantasy data is intended to be used to generate roster, lineup, waiver, matchup, injury, and related fantasy-management analysis.

03

Transactions

If write access is approved and implemented in the future, lineup or roster changes are intended to be initiated or explicitly approved by the authenticated user.

04

Initial scope

The initial product is intended for personal use with a low volume of API requests, with expansion only after the appropriate platform access and requirements are satisfied.
